# Linguagem Técnica de Programação

Repositório destinado aos exercícios, atividades e práticas desenvolvidas durante a disciplina de **Linguagem Técnica de Programação**, utilizando a linguagem **C**.

O objetivo deste repositório é acompanhar minha evolução durante a disciplina, desde os conceitos iniciais da linguagem até a construção de programas mais completos.

## Conteúdos praticados

Até o momento:

* Estrutura básica de um programa em C
* `printf`
* `scanf`
* Variáveis
* Tipos `int` e `float`
* Operações matemáticas
* Constantes com `#define`
* Formatação de valores numéricos

## Exercícios

### Hello World

Primeiro programa desenvolvido em C, utilizado para conhecer a estrutura básica da linguagem e realizar a primeira compilação.

Arquivo:

`HelloWorld.c`

### Soma de dois números

Programa que recebe dois números inteiros informados pelo usuário e apresenta o resultado da soma.

Arquivo:

`SOMA.c`

### Área do círculo e trapézio

Programa que recebe valores informados pelo usuário e calcula:

* Área de um círculo
* Área de um trapézio

Arquivo:

`area_circulo_trapezio.c`
